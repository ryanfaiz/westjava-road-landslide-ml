Cara Kerja Model Prediksi

            

              

                
Logistic Regression

                

                  Menghitung probabilitas suatu sampel termasuk kelas tertentu berdasarkan kombinasi linear fitur menggunakan fungsi logistik (sigmoid). Klasifikasi ditentukan berdasarkan ambang probabilitas yang ditetapkan.
                

              

              

                
Support Vector Machine (SVM)

                

                  Mencari hyperplane terbaik yang memisahkan kelas positif dan negatif dengan margin terbesar. Kernel dapat digunakan untuk menangani pola hubungan nonlinier antarfitur.
                

              

              

                
Random Forest

                

                  Menggabungkan prediksi dari banyak Decision Tree yang dibangun menggunakan sampel data dan subset fitur secara acak. Hasil klasifikasi ditentukan melalui voting mayoritas dari seluruh pohon.
                

              

              

                
XGBoost

                

                  Membangun model secara bertahap menggunakan kumpulan Decision Tree, dengan setiap pohon baru berusaha memperbaiki kesalahan prediksi model sebelumnya. Proses optimasinya menggunakan gradient boosting dengan regularisasi untuk mengurangi risiko overfitting.
                

              

          

          

          

            
Spatial
              IDW 5-Pixel Interpolation Engine

            

              Koordinat di luar 632 titik sampel koridor jalan provinsi diekstraksi secara dinamis menggunakan
              interpolasi Inverse Distance Weighting (IDW) berbasis 5 piksel DEM SRTM & CHIRPS terdekat.
